# Nexment Website

The official website of **The Nexment Project**.

This website is the main public-facing home of Nexment, where you can learn about the project, explore what we're building, and find links to our projects and resources.

## About Nexment

**The Nexment Project** is an independent software project focused on building useful, simple, and accessible technology.

This repository contains the source code for the Nexment main website.

## Tech Stack

- Next.js
- React
- TypeScript
- Modular CSS
- Font Awesome
- Google Fonts / Self-hosted fonts

## Project Structure

The website is built with the Next.js App Router.

```text
.
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── public/
│   ├── fonts/
│   └── other assets
├── package.json
└── README.md
```

## Development

Clone the repository and install the dependencies:

```bash
git clone https://github.com/theNexmentProject/nexment-website.git
cd nexment-website
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available at:

`http://localhost:3000`
